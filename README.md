### Описание варианта 6.
В input.txt записан список рецептов создания предметов в формате: Название_предмета: ID1 ID2 ID3 (например, Каменный_топор: 1 1 2, где цифры — это ID необходимых ресурсов из инвентаря). Программа должна проверить каждый рецепт, сопоставив требуемые ID с текущим массивом inventory игрока (учитывая количество одинаковых предметов!). В output.txt вывести вердикт по каждому рецепту: [ДОСТУПНО] или [НЕ ХВАТАЕТ РЕСУРСОВ] с указанием названий недостающих компонентов.
